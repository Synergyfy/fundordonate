# FundOrDonate — Phase 2: Public-Facing Website

## 1. Purpose

Phase 2 transforms FundOrDonate's public-facing experience into a polished, premium crowdfunding website while retaining the approved visual identity, existing codebase, and Phase 1 architecture.

## 2. Final Homepage Architecture

The homepage is a single-page experience composed of 20+ distinct sections, each using the `Section` scroll-reveal wrapper for progressive disclosure. The complete section order follows the prescribed visitor journey:

```
Hero → Statistics → Featured → Trending → Recent → Ending Soon →
Categories → Funding Opportunities → Business Funding → How It Works →
Why FundOrDonate → Rewards/E-Card → Self-Funding → Seasonal →
Evergreen → Testimonials → Community → MCOM Ecosystem →
Mobile VCard → Video → Campaign CTAs → FAQ → Final CTA
```

## 8. Animated Text

- Badge uses `animate-fade-in`
- All animations use `animation-fill-mode: both` for proper initial state

## 9. AOS-Style Scroll Animations

- **File:** `apps/web/src/hooks/useScrollReveal.ts`
- IntersectionObserver-based with configurable threshold and rootMargin
- Default: 10% visible, 60px bottom margin
- Once-triggered (default) for performance
- Applied via `Section` wrapper component
- CSS transition: `duration-700 ease-out` with `opacity-0/translate-y-8` → `opacity-100/translate-y-0`

## 42. Known Limitations

1. **No pre-existing SVG/Lottie assets** — The repository contained no custom illustrations. Hero artwork is created as inline SVG with CSS animations.

2. **Video section is visual-only** — The video popup section displays a play button but requires external video URL configuration to function.

3. **Dashboard/admin pages use USD** — Pre-existing pages outside Phase 2 scope. Will be aligned to GBP in a future phase.

4. **Social links are placeholder** — Footer social links use `#` hrefs until actual social media accounts are configured.

5. **Statistics are real where available** — Campaign count, raised amount, and backer count come from API data. "Success Rate" is a placeholder until analytics are implemented.

6. **Testimonials are approved content** — Community quotes are representative examples, not fabricated testimonials.
