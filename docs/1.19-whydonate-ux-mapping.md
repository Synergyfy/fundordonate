# 1.19 — WhyDonate UX Reference Mapping

## Purpose
Map WhyDonate UX patterns as quality benchmarks. FundOrDonate must achieve equal or better UX quality while maintaining its own visual identity.

---

## Homepage

| WhyDonate Pattern | Why It Works | FundOrDonate Adaptation | Existing GrowFund | New Component | Phase |
|---|---|---|---|---|---|
| Hero with tagline + primary CTA | Immediate value proposition, clear first action | Hero with FundOrDonate tagline + "Start a Campaign" CTA | Home (inline) | HeroSection | Phase 2 |
| Featured campaigns carousel | Shows active campaigns immediately | Featured campaigns grid/slider | FeaturedCampaigns | FeaturedCampaigns (enhance) | Phase 2 |
| Category navigation | Quick browse by interest | Category pills/tabs | CampaignFilters | CategoryNav | Phase 2 |
| Statistics counter (raised, campaigns, backers) | Social proof at scale | Stats counter bar | None | StatsBar | Phase 2 |

| Success stories/testimonials | Builds trust | Campaign success stories carousel | None | SuccessStories | Phase 2 |
| Newsletter signup | Captures leads | Optional newsletter CTA in footer | None | NewsletterSignup | Phase 3 |
