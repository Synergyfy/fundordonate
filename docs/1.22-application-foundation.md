# FundOrDonate — Application Foundation & Shared Domain Contracts

> Phase 1E: Centralized configuration, shared domain types, service boundaries, and API helpers.

## Overview

Phase 1E establishes the application foundation layer — the shared constants, utilities, configuration, and domain services that all other code depends on. This replaces scattered hardcoded values with authoritative single sources of truth.

---

## Known Limitations

1. **`@fundordonate/types` Vite Resolution**: Vite/Rollup cannot resolve `export *` re-exports from the shared types package at build time. Frontend code inlines utility functions and constants as a workaround. This is a known limitation; the TypeScript compiler resolves these imports correctly (hence `tsc --noEmit` passes), but the bundler fails.

2. **JWT `expiresIn` Type**: The `@types/jsonwebtoken@9.0.10` overload expects `number | StringValue` for `expiresIn`, but our config stores it as `string`. Cast to `any` is used as a pragmatic workaround.

3. **Role Type Casting**: `req.userRole` and `user.role` from Prisma are `string`, requiring `as Role` casts when passed to typed functions.
